# Angular Projects

This repository contains various Angular projects and implementations.

## Project Structure

- **angular-material-component/** - Angular Material UI components.
- **angular-material-table/** - Implementation of Angular Material tables.
- **angular-metanit/** - Examples and tutorials from Metanit.
- **angular-pragim-tech/** - Angular tutorials from PragimTech.
- **angular_official_docs/** - Projects and examples from Angular's official documentation.
- **architecture-angular-aspnet/** - Architectural patterns combining Angular and ASP.NET.
- **load-excel-dotnet-angular/** - Uploading and processing Excel files using .NET and Angular.
- **pro-angular-5ed/** - Advanced Angular projects based on "Pro Angular" (5th Edition).
- **quiz-aspnet-angular/** - A quiz application using ASP.NET and Angular.

## Requirements

- Node.js and npm
- Angular CLI
- .NET Core (if using ASP.NET backend)

## Setup & Usage

1. Clone the repository:
   ```sh
   git clone https://github.com/Abdujalilc/angular-projects.git
   ```
2. Navigate into the desired project directory:
   ```sh
   cd angular-material-table  # or any other project
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Run the Angular project:
   ```sh
   ng serve
   ```
